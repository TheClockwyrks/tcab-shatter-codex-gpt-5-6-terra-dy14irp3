# Shatter

Shatter is a browser gravity-well rock shooter. Drift through deep space, break armored asteroids into fragments, bend shots around a hungry star, and save your homing torpedo for the moment it matters.

## Run it

```bash
npm ci
npm run dev
```

Build a static production site with `npm run build`. The finished site is in `dist/`.

## Controls

- `ARROWS` or `WASD` — thrust and turn
- `SPACE` — fire
- `F` — launch the homing torpedo
- `ENTER` — select menu item
- `ESC` / `P` — pause or go back
- `M` — mute
